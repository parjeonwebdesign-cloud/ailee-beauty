# AILÉE (에밀레) — Glass & Light Beauty Platform

> **"빛을 향해 피어나는 날개"**  
> 맑고 투명한 유리알 광택과 맞춤형 퍼스널 컬러 쉐이드 매칭을 제공하는 럭셔리 K-뷰티 브랜드 플랫폼입니다.

---

## ✨ 주요 기능 (Key Features)

1. **퍼스널 컬러 쉐이드 매칭 (Personalized Shade Finder)**
   - 3초 정밀 진단 퀴즈로 웜톤/쿨톤 및 세부 피부 톤에 맞는 베스트 립/쿠션/하이라이터 쉐이드 추천
2. **실시간 컬러 비교기 (Shade Comparator)**
   - 선택한 쉐이드와 추천 쉐이드를 한눈에 실시간으로 대조 비교
3. **인터랙티브 쇼핑 & 위시리스트 (Interactive Shop & Cart)**
   - 유리알 젤리 글레이즈 틴트, 클라우드 블러 립 무스, 글래스 베일 하이라이터 등 시그니처 라인업 탐색 및 장바구니/위시리스트 담기
4. **감성 브랜드 스토리 & 저널 (AILÉE Journal)**
   - AILÉE만의 영감의 오브제(Glass, Light, Water & Jelly, Pearl & Gloss, Wings)와 뷰티 저널

---

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Animation**: Motion (`motion/react`)

---

## 🚀 시작하기 (Getting Started)

### 1. 프로젝트 클론 및 패키지 설치

```bash
git clone https://github.com/YOUR_USERNAME/ailee-beauty-app.git
cd ailee-beauty-app
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 후 확인하실 수 있습니다.

### 3. 프로덕션 빌드

```bash
npm run build
```
